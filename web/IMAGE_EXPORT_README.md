# 图片导出功能使用说明

## 📸 功能介绍

已为"核心指数"和"行业指数"页面添加了精美的图片导出功能，可以一键将排名表格导出为高质量 PNG 图片，方便分享。

## 🎨 导出效果特点

- ✅ **精美设计**：渐变色表头、圆角徽章、彩色标识
- ✅ **高分辨率**：2倍缩放，清晰锐利
- ✅ **智能布局**：自动显示前20名，避免图片过长
- ✅ **视觉优化**：
  - 前三名使用金色/橙色渐变徽章
  - 正负值使用红绿配色
  - 偏离率带背景色高亮
  - 排序变化带彩色标签
  - 脉冲动画标识（使用上一交易日数据）

## 🚀 安装依赖

在项目根目录或 web 目录下执行：

```bash
cd web
npm install html2canvas
```

或者使用 PowerShell：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
cd web
npm install html2canvas
```

## 💡 使用方法

1. 打开"核心指数"或"行业指数"页面
2. 选择要导出的交易日（可选，默认最新）
3. 点击右上角 **"📷 导出图片"** 按钮
4. 等待生成，自动下载 PNG 文件
5. 文件名格式：`核心指数趋势排名_2026.09.03.png`

## 📁 文件说明

### 新增文件
- `web/src/components/ShareCard.tsx` - 精美分享卡片组件

### 修改文件
- `web/src/App.tsx` - 添加导出功能和按钮

## 🔧 技术细节

- 使用 `html2canvas` 库将 DOM 元素转换为 Canvas
- 2倍缩放保证高清输出
- 动态导入，不影响首屏加载速度
- 隐藏的 ShareCard 组件用于渲染，不影响页面布局

## ⚠️ 注意事项

1. 如果导出失败，请确认已安装 `html2canvas` 依赖
2. 图片仅显示前20条数据，避免文件过大
3. 建议在 Chrome/Edge 浏览器中使用以获得最佳效果
