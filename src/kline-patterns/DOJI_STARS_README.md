# 十字启明星和十字黄昏之星形态说明

## 概述

新增了两种更精确的K线反转形态识别：**十字启明星**（Doji Morning Star）和**十字黄昏之星**（Doji Evening Star）。

## 形态定义

### 十字启明星 (Doji Morning Star) - 看涨信号

**特征：**
1. 第一日是长阴线（下跌趋势延续）
2. 第二日是**真正的十字星**（开盘价和收盘价非常接近，实体不超过总范围的10%）
3. 第三日是长阳线（上涨反转）

**含义：**
- 十字星表示市场在经历下跌后陷入犹豫不决
- 随后的阳线确认了多头力量的回归
- 比普通启明星信号更强，因为十字星代表了更明确的多空平衡点

**置信度：** 基础置信度 0.8（普通启明星为 0.7）

### 十字黄昏之星 (Doji Evening Star) - 看跌信号

**特征：**
1. 第一日是长阳线（上涨趋势延续）
2. 第二日是**真正的十字星**（开盘价和收盘价非常接近，实体不超过总范围的10%）
3. 第三日是长阴线（下跌反转）

**含义：**
- 十字星表示市场在经历上涨后陷入犹豫不决
- 随后的阴线确认了空头力量的回归
- 比普通黄昏之星信号更强，因为十字星代表了更明确的多空平衡点

**置信度：** 基础置信度 0.8（普通黄昏之星为 0.7）

## 识别优先级

系统会**优先检测十字形态**，如果符合十字形态条件，则不再检测普通形态：

```typescript
// 检测逻辑
1. 检测十字启明星 → 如果匹配，返回"十字启明星"
2. 检测十字黄昏之星 → 如果匹配，返回"十字黄昏之星"
3. 检测普通启明星 → 如果匹配，返回"启明星"
4. 检测普通黄昏之星 → 如果匹配，返回"黄昏之星"
```

## 十字星判断标准

第二根K线必须满足以下条件才被认为是"真正的十字星"：

```typescript
实体大小 = |收盘价 - 开盘价|
总范围 = 最高价 - 最低价

条件：实体大小 <= 总范围 × 10%
```

这个标准与单根K线形态识别器中的十字星判断标准保持一致。

## 示例数据

### 十字启明星示例

```javascript
// 第一日：阴线
{ open: 105, high: 108, low: 93, close: 98 }

// 第二日：十字星（实体0.2，范围6，占比3.3% < 10%）
{ open: 95, high: 98, low: 92, close: 95.2 }

// 第三日：阳线
{ open: 100, high: 110, low: 95, close: 108 }
```

### 十字黄昏之星示例

```javascript
// 第一日：阳线
{ open: 98, high: 108, low: 97, close: 105 }

// 第二日：十字星（实体0.3，范围6，占比5% < 10%）
{ open: 105, high: 108, low: 102, close: 105.3 }

// 第三日：阴线
{ open: 100, high: 105, low: 90, close: 92 }
```

## 数据库存储

新形态使用以下 `patternType` 值存储在数据库中：

- 十字启明星：`doji_morning_star`
- 十字黄昏之星：`doji_evening_star`

对应的 `patternName` 值为：

- 十字启明星：`十字启明星`
- 十字黄昏之星：`十字黄昏之星`
