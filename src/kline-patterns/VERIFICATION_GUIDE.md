# K线形态计算验证功能使用说明

## 功能概述

K线形态计算验证功能允许你批量或单个计算指定交易日的K线形态，用于验证计算算法的准确性。通过该功能，你可以：

- ✅ 选择特定交易日进行计算（默认当天）
- ✅ 批量计算多个指数的K线形态
- ✅ 单个指数精确验证
- ✅ 实时查看计算结果和形态详情
- ✅ 对比不同指数的形态识别结果

## 访问路径

管理后台地址：`http://localhost:5173/admin/kline-pattern-verification`

或通过管理后台左侧菜单点击 **"🔍 形态验证"** 进入。

## 使用步骤

### 1. 选择交易日期

- 默认设置为当前日期
- 可以手动选择历史任意交易日
- 建议从已有数据的日期开始验证

### 2. 选择指数

系统会自动加载所有标记为"参与K线形态计算"的指数列表。

- **全选/取消全选**：快速选择所有指数
- **单独选择**：勾选需要验证的具体指数
- 支持多选，可同时验证多个指数

### 3. 执行计算

点击 **"开始计算"** 按钮，系统会：

1. 对每个选中的指数调用K线形态分析算法
2. 获取趋势状态、主要形态、所有检测到的形态
3. 返回详细的计算结果

### 4. 查看结果

计算完成后，页面会展示：

#### 成功计算的指数

每个成功的结果包含：

- **指数信息**：名称、代码
- **趋势状态**：上升趋势/下降趋势/横盘趋势
- **主要形态**：
  - 形态名称
  - 置信度（进度条显示）
  - 信号类型（看涨/看跌/中性）
- **所有检测到的形态**：列出该交易日识别出的所有形态及其置信度

#### 失败的指数

显示失败原因，如：
- 数据不足
- 指数不存在
- 其他错误信息

## API接口说明

### 批量计算接口

```
POST /kline-patterns/calculate-verify
```

**请求参数：**

```json
{
  "tradeDate": "2026-09-12",  // 可选，默认为当天
```

## 使用场景

### 场景1：验证单日计算准确性

1. 选择一个已知有明确形态的历史日期
2. 选择一个或多个指数
3. 执行计算并检查结果是否符合预期

### 场景2：批量验证一段时间内的形态

1. 选择一个日期范围
2. 逐个日期执行计算
3. 观察形态变化的连续性

### 场景3：对比不同指数的形态识别

1. 同时选择多个指数
2. 执行计算
3. 在结果列表中横向对比各指数的形态识别结果

## 注意事项

⚠️ **重要提示：**

1. **数据完整性**：确保所选日期有足够的历史K线数据（至少30根用于趋势判断）
2. **计算性能**：批量计算大量指数可能需要较长时间，请耐心等待
3. **结果持久化**：计算结果会保存到数据库（非实时模式），可通过查询接口再次查看
4. **置信度参考**：形态置信度仅供参考，高置信度不代表必然发生

## 技术实现

### 后端

- **DTO**: `CalculateKLinePatternDto` - 定义计算参数
- **Service**: 
  - `getParticipatingIndices()` - 获取参与计算的指数列表
  - `batchCalculateForVerification()` - 批量计算逻辑
- **Controller**: `calculateVerify()` - 处理计算请求

### 前端

- **组件**: `KLinePatternVerification.tsx` - 验证界面
- **API**: `calculateKLinePatternVerify()` - 调用后端接口
- **路由**: `/admin/kline-pattern-verification` - 管理后台入口

## 常见问题

**Q: 为什么有些指数计算失败？**

A: 可能的原因：
- 该日期没有足够的历史K线数据（需要至少30根）
- 指数未标记为"参与K线形态计算"
- 数据源异常

**Q: 如何查看已保存的计算结果？**

A: 可以通过 `/admin/kline-patterns` 页面的查询功能，按日期和指数筛选查看。

**Q: 能否导出计算结果？**

A: 当前版本暂不支持导出，可以通过浏览器开发者工具获取API响应数据。
