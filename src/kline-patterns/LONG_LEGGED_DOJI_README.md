# 捉腰带形态 (Long Legged Doji) 说明

## 概述

新增了两种单根K线反转形态识别：**看涨捉腰带线**和**看跌捉腰带线**。这两种形态是重要的趋势反转信号。

## 形态定义

### 看涨捉腰带线 (Bullish Long Legged Doji) - 看涨信号

**特征：**
1. 开盘价等于最低价（或非常接近，偏差<5%）
2. 收阳线（收盘价 > 开盘价）
3. 有很长的上影线（至少是实体大小的2倍）
4. 没有下影线或很短（不超过实体的10%）

**含义：**
- 开盘后价格立即下跌但迅速被拉起
- 长上影线表明多头力量强劲，成功将价格推高
- 是强烈的底部反转信号

**置信度：** 基础置信度 0.75

**支撑/阻挡位：**
- 支撑位：开盘价（即最低价）
- 阻挡位：最高价

**示例数据：**
```javascript
{ open: 100, high: 120, low: 100, close: 106 }
// 实体大小=6, 上影线=14, 下影线=0
// 上影线/实体 = 14/6 = 2.33 > 2 ✓
```

### 看跌捉腰带线 (Bearish Long Legged Doji) - 看跌信号

**特征：**
1. 收盘价等于最高价（或非常接近，偏差<15%）
2. 收阴线（收盘价 < 开盘价）
3. 有很长的下影线（至少是实体大小的2倍）
4. 没有上影线或很短（不超过实体的10%）

**含义：**
- 开盘后价格大幅下跌，但尾盘被拉回
- 长下影线表明空头力量在盘中占据主导
- 是强烈的顶部反转信号

**置信度：** 基础置信度 0.75

**支撑/阻挡位：**
- 阻挡位：收盘价（即最高价）
- 支撑位：最低价

**示例数据：**
```javascript
{ open: 110, high: 110, low: 85, close: 107 }
// 实体大小=3, 上影线=0, 下影线=22
// 下影线/实体 = 22/3 = 7.33 > 2 ✓
```

## 识别优先级

系统会**优先检测捉腰带形态**，如果符合捉腰带条件，则不再检测锤子线、上吊线等类似形态：

```typescript
// 检测逻辑顺序
1. 检测十字星
2. 检测捉腰带形态 → 如果匹配，返回捉腰带形态并停止
3. 检测大阳线/大阴线
4. 检测锤子线/上吊线
5. 检测倒锤子线/射击之星
```

这种优先级设计确保了更精确的形态能够被正确识别。

## 判断标准详解

### 看涨捉腰带线条件

```typescript
1. candle.close > candle.open (阳线)
2. |candle.open - candle.low| / totalRange < 0.05 (开盘价≈最低价)
3. upperShadow > bodySize * 2 (上影线长度 > 实体*2)
4. lowerShadow < bodySize * 0.1 (下影线很短)
5. bodySize >= totalRange * 0.1 (实体不能太小，避免与十字星混淆)
```

### 看跌捉腰带线条件

```typescript
1. candle.close < candle.open (阴线)
2. |candle.close - candle.high| / totalRange < 0.15 (收盘价≈最高价)
3. lowerShadow > bodySize * 2 (下影线长度 > 实体*2)
4. upperShadow < bodySize * 0.1 (上影线很短)
5. bodySize >= totalRange * 0.1 (实体不能太小，避免与十字星混淆)
```

## 置信度计算

捉腰带形态的置信度基于以下因素：

1. **基础置信度**：0.75
2. **影线长度加成**：
   - 影线/实体 > 3：+0.1
   - 影线/实体 > 4：+0.1
3. **实体大小加成**：
   - 实体/总范围 > 0.3：+0.05

**最大置信度**：1.0

## 数据库存储

新形态使用以下 `patternType` 值存储在数据库中：

- 看涨捉腰带线：`bullish_long_legged_doji`
- 看跌捉腰带线：`bearish_long_legged_doji`

对应的 `patternName` 值为：

- 看涨捉腰带线：`看涨捉腰带线`
- 看跌捉腰带线：`看跌捉腰带线`

## 与其他形态的区别

### vs 锤子线/上吊线

- **锤子线**：下影线很长，但实体不在顶端
- **看涨捉腰带线**：开盘价=最低价，实体在底端

### vs 倒锤子线/射击之星

- **倒锤子线**：上影线很长，但实体不在底端
- **看跌捉腰带线**：收盘价=最高价，实体在顶端

### vs 十字星

- **十字星**：实体非常小（<总范围10%）
- **捉腰带线**：实体适中（≥总范围10%）

## 实际应用建议

1. **看涨捉腰带线**出现在下跌趋势底部时，是强烈的买入信号
2. **看跌捉腰带线**出现在上涨趋势顶部时，是强烈的卖出信号
3. 建议配合成交量验证：成交量放大时信号更强
4. 建议结合趋势分析：在明确的趋势反转点出现时置信度更高
