# 上证指数十年跨度涨跌统计分析

## 📊 分析概述

本分析工具用于统计上证指数在任意10年跨度内的上涨和下跌天数，并计算相应的概率分布。通过分析2006年至2025年的数据，我们可以发现市场的长期趋势特征。

## 🔧 使用的脚本文件

### 1. `analyze_decades.js` - 核心分析脚本
- **功能**: 读取CSV数据，执行统计分析
- **输入**: `temp_test/index_histories_202609161614.csv`
- **输出**: `temp_test/decade_analysis_results.json`
- **运行方式**: 
  ```bash
  node analyze_decades.js
  ```

### 2. `display_decade_analysis.js` - 文本报表生成器
- **功能**: 将JSON结果格式化为美观的文本表格
- **输入**: `temp_test/decade_analysis_results.json`
- **输出**: 控制台格式化报表
- **运行方式**: 
  ```bash
  node display_decade_analysis.js
  ```

### 3. `temp_test/decade_analysis.html` - 可视化网页
- **功能**: 提供交互式图表和数据展示
- **输入**: `temp_test/decade_analysis_results.json`
- **运行方式**: 在本地服务器中打开或通过浏览器访问

## 🎯 分析方法

### 数据定义
- **上涨日**: 当日涨跌幅 > 0%
- **下跌日**: 当日涨跌幅 < 0%  
- **平盘日**: 当日涨跌幅 = 0%

### 滚动窗口策略
采用逐年移动的10年窗口进行分析：
- 第1个窗口: 2006-2016 (11年完整周期)
- 第2个窗口: 2007-2017
- ...
- 最后一个窗口: 2015-2025

每个窗口包含约2600+个交易日，确保统计结果的可靠性。

## 💡 使用建议

1. **重新运行分析**: 修改CSV文件后，重新运行 `node analyze_decades.js`
2. **查看可视化**: 启动本地服务器后访问HTML页面获得更好的视觉体验
3. **自定义分析**: 可修改脚本以支持不同的时间跨度（如5年、15年等）
